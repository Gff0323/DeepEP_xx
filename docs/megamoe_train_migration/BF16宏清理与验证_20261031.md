## 唯一的前反向 Dispatch 逃生构建选项

```bash
export DEEPEP_BF16_FORCE_EXPERT_READY=OFF  # 默认：现有自动策略
export DEEPEP_BF16_FORCE_EXPERT_READY=ON   # 逃生：前反向均等整专家 Dispatch 完成
```

同名 CMake option 支持 `ON/OFF`，构建系统给 Host 和 Device 一致传入数值 `1/0`。

- OFF：保留现有细分、自动选择和小专家回退。
- ON：前向停用 tile-ready 和 prepared metadata，使用既有整专家完成计数；反向 Host/Device 都固定 `splitExperts=0`，停用行就绪及相应 metadata。不同专家之间仍可重叠，不增加全 EP 屏障。
- ON 的优先级高于反向诊断环境变量 `MEGAMOE_BF16_BWD_DISPATCH_SPLIT_EXPERTS`；OFF 保留原环境变量语义。
- 切换需要完整重建并安装 wheel，全部 EP rank 使用同一构建；不能只替换一个 SO。构建缓存、setuptools 构建目录和安装的 `_build_info.json` 都记录/区分该策略。

保持不变：Python 包和 `MegaMoeBF16Train` 接口、`_C.BF16`、kernel C 导出签名、`libdeepep_megamoe_train_bf16.so` 名称和 SONAME、保存区布局及后续偏移。
